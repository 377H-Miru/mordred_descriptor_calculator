# Example Usage

This directory contains sample files demonstrating how to use `mordred-desc`.

## Running with CLI arguments

```bash
mordred-desc --input examples/sample.csv --output output.csv --smiles-col smiles --id-col compound_id --only-2d --overwrite
```

## Running with JSON Configuration

```bash
mordred-desc --config examples/job_config.json --overwrite
```
